# hydromotor_machine_sales

Odoo 19.0 **development-test candidate** reconstructed from the latest supplied SaaS 19.4 backup.

Install only in a NEW disposable Odoo 19.0 database, not into an existing copy of the older candidate.

Runtime installation, business workflows, permissions and PDF rendering have NOT been tested here.

The original x_hm_* technical model/field names and custom action logic are preserved. SaaS 19.4 ir.access definitions are converted into Odoo 19.0 ACLs and record rules. Company restrictions remain global rules. No customer records, invoices, authentication credentials, subscription details, mail-server settings or attachments are installed.

Read the bundle RECOVERY_REPORT.md and ACCEPTANCE_TESTS.md before deployment.
